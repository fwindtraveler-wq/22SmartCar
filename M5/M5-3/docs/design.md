# M5-3 集成架构与分层急停

## 集成架构

裁判指令由 `referee_bridge.py` 解析，状态推送给操作终端和 M5-2 面板；任务
控制、热切换、安全与审计都通过同一个 Web UI 完成，不开新终端、不 SSH。

## 分层急停

| 层 | 动作 | 目的 |
| :-- | :-- | :-- |
| 指令层 | 发布 `/cmd_vel` 零速度 | 常规停车 |
| 话题层 | 发布 `/emergency_stop` | 让底盘订阅者自己锁存 |
| 控制器层 | 调用控制器软急停 | 防止控制器超时后恢复 |
| 记录层 | 写黑匣子 + 审计日志 | 赛后追溯 |

急停后不会自动恢复；`reset` 接口要求 `confirm=true`，物理按钮和语音指令也
走同一条命令通道，避免两套逻辑漂移。语音唤醒词只触发“请求确认”，不直接急停。

## 热切换

`hot_switch.py` 只调用加载器，不重启节点。新资源加载失败时保留旧资源并返回
错误，同时写 `switch_log.csv` 和审计日志。
